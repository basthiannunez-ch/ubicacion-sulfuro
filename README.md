# Ubicación QR · Campamento Sulfuro, Centinela

Página web del proyecto de ubicación con códigos QR (Mantención Newrest).

- Página: https://basthiannunez-ch.github.io/mapa/
- Cada QR abre la página con el punto marcado como "Estás aquí" (ej. `#p-21`).
- "Voy a" traza el camino en el plano con la distancia, el tiempo a pie y la dirección.
- "Usar mi ubicación (GPS)" muestra tu posición en vivo y cuánto te falta para llegar.

Los QR y el generador están en la carpeta `agente-electrico/proyectos/ubicacion_qr` del PC.
